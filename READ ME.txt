Gaeltec Tools page - version 10-Nov-2026b

QUICKEST: upload index.html to GitHub, replacing the old index.html (keep the name
index.html, all lowercase). Wait 1-2 minutes, then open the page with Ctrl + F5.
The header should say "version 10-Nov-2026b".

TO KEEP BUILDING IT YOURSELF: copy the other files in this folder into your page
folder (next to build_page.py), replacing the old ones, then run:
    python build_page.py

JUPYTER: generator_sync.py is the same code as tool_generator_sync.py - put it next
to your notebook (replacing the old one) and run:
    import generator_sync; generator_sync.launch()

What changed
  - Generators (task 1, Planning -> Tracker): new outages go in date order. A date
    that falls between dates already in the tracker gets a new row there - the rows
    below move down with all their columns (generator details, status ...), and the
    Weekday formula follows. Same date = after the existing ones. The preview says
    "inserted in date order (before current row N)" or "at the end".
  - Financial dashboard > new "Teams" tab: tick which teams (from the control file
    team column) build the Teams chart in Trends, and optionally type the team
    leader shown next to each team ("T1 · John Smith"). "Use leaders from file"
    fills in the leader that appears most for each team. Remembered in this browser.
  - Financial charts renamed: "Revenue", "Teams", "PID Breakdown" (no descriptions).
  - The "N row(s) not classified" warning is gone from the Financial dashboard.
  - A very soft click sound when you click a tool, dashboard or link on the home page.
  - Planning dashboard > Overview: new "Source files -> circuits -> most repeated job"
    table (above the Plan1 comments). One line per source file; click it to open its
    circuits, each with the job repeated most for that circuit in that file. Search,
    Open all / Close all and CSV download. Follows the same filters as the page.
