Gaeltec Tools page - version 12-Nov-2026

QUICKEST: upload index.html to GitHub, replacing the old index.html (keep the name
index.html, all lowercase). Wait 1-2 minutes, then open the page with Ctrl + F5.
The header should say "version 12-Nov-2026".

TO KEEP BUILDING IT YOURSELF: copy the other files in this folder into your page
folder (next to build_page.py), replacing the old ones, then run:
    python build_page.py

JUPYTER: generator_sync.py is the same code as tool_generator_sync.py - put it next
to your notebook (replacing the old one) and run:
    import generator_sync; generator_sync.launch()

What changed
  - Generators (task 1, Planning -> Tracker): new outages go in date order. A date
    that falls between dates already in the tracker gets a new row there - the rows
    below move down with all their columns (generator details, status ...), and the
    Weekday formula follows. Same date = after the existing ones. The preview says
    "inserted in date order (before current row N)" or "at the end".
  - Financial dashboard > new "Teams" tab: tick which teams (from the control file
    team column) build the Teams chart in Trends, and optionally type the team
    leader shown next to each team ("T1 · John Smith"). "Use leaders from file"
    fills in the leader that appears most for each team. Remembered in this browser.
  - Financial charts renamed: "Revenue", "Teams", "PID Breakdown" (no descriptions).
  - The "N row(s) not classified" warning is gone from the Financial dashboard.
  - A very soft click sound when you click a tool, dashboard or link on the home page.
  - Planning dashboard > Overview: new "Source files -> circuits -> most repeated job"
    table (above the Plan1 comments). One line per source file; click it to open its
    circuits, each with the job repeated most for that circuit in that file. Search,
    Open all / Close all and CSV download. Follows the same filters as the page.
  - Every dashboard chart has a "PNG" button: downloads the chart as a picture with
    its title and legend (white background, sharp at 2x size).
  - The CV7_recover picture (Planning > Overview) shows the value on top of every bar,
    whatever the grouping (day / week / month).
  - Planning dashboard: new date field "Blanks" = rows whose Plan1 date has already
    passed (before today) and still have no Done date; they are dated by Plan1, so the
    range and every tab work as usual. The Overview shows "Blanks comments - most
    repeated" (the comments written on those rows).
  - Planning > Overview: the "most repeated comments" card now also shows for
    Combined date (the default), Blanks and Unplanned (as well as Plan1), always
    below the source-file table.
  - Planning > Overview: hovering a bar (CV7_recover over time, Unplanned poles) now
    lists the circuits and job names behind it, biggest first (top 8 + "N more").
  - Source-file table: new "Dates" column - the dates of that circuit's most repeated
    job (for a source file: all its rows), always inside the date field/range picked
    at the top. One date, or "first -> last · N dates". Also in the CSV.

11-Nov-2026
  - Financial > Teams: teams are read letter by letter (A, B, C … L). Combinations
    such as AB, AC, DE, A/B are split equally between those teams in the Teams chart,
    which only shows single letters. Each letter's leader is taken from the control
    files (the name on that team's own rows) and shown as "A · Ann"; type a name in
    the Teams tab to change it ("Reset to file leaders" goes back).
  - Generators > step 6 "Email for the generator provider (Outlook)": read the
    Generator Tracker (the planning file is optional for this), pick dates, tick the
    generators, Write email. Copy email (paste into Outlook, bullets kept), Open in
    Outlook (.eml draft) or Open in mail app. To / Cc are remembered.
    Uses: PTE – Customer Adress – (///What3words), then (xN) type – phase – kVa –
    m of cable; the time = Schedule - start (08:30am if blank); days needed = the
    column right after Schedule - Finish (blank = 1 day, a number = that many days,
    a date = last day).
